# Orbitas Indexer MCP

Read-only MCP interface for AI agents over the Orbitas Subgraph.

## Tools

- `orbitas_index_health`
- `orbitas_get_passport`
- `orbitas_get_obligation`
- `orbitas_list_obligations`
- `orbitas_get_incoming_obligations`
- `orbitas_get_outgoing_obligations`
- `orbitas_find_local_paths`
- `orbitas_get_settlement`

Candidate paths are projections only. Before settlement, canonical contracts and consent policies must be revalidated.

Supports MCP SDK v2 stdio and Streamable HTTP entrypoints.
